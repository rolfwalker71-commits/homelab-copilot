Proxmox & Docker

Zweiter Proxmox-Host (standalone)

Eigenständiger zweiter PVE, kein Cluster-Mitglied von Host 1. Copilot spricht ihn nur über diese eigene URL/Token an — niemals über die API von Host 1 (/nodes/pve02/status). Leer lassen, wenn du nur einen Host hast. Wird mit Speichern in der Datenbank abgelegt — nicht in .env — und bleibt nach Neustart erhalten.

Derselbe SSH-Schlüssel (DOCKER_SSH_KEY_PATH bzw. data/ssh/id_ed25519) wird für Docker-Discovery, Container-Steuerung und das Browser-Terminal auf Guest-Karten verwendet.
